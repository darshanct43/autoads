# AutoAds Cinematic Portfolio — Official Shopify OS 2.0 Theme

This is a complete, native Shopify OS 2.0 theme built for the **AutoAds Cinematic Brand Story & Advertising Platform**.

## Theme Features
- **60fps Cinematic Video Scrubbing**: Full canvas rendering driven by page scroll.
- **7 Motion Scenes**: Platform, Transit Media, Hyperlocal Pincodes, Omnichannel, Instant Launch, Gym & Fitness, Viral Reels.
- **Sound Design**: Web Audio API ambient synthesizer drone engine.
- **Discovery Hub**: 5-stage campaign roadmap, 38 Indian cities matrix, full FAQs, interactive city cards.
- **Shopify Online Store 2.0 Architecture**: Modular JSON templates, liquid sections, and customizer-friendly settings.

## How to Install in Shopify

### Method A: Connect from GitHub
1. Create a new repository on your GitHub (e.g. `autoads-shopify-theme`).
2. Push this directory to the repository `main` branch:
   ```bash
   git remote add origin https://github.com/darshanct43/autoads-shopify-theme.git
   git branch -M main
   git push -u origin main
   ```
3. In your Shopify Admin, go to **Online Store > Themes > Add theme > Connect from GitHub**.
4. Select `autoads-shopify-theme` and click **Connect**.

### Method B: Upload Theme ZIP Directly
1. In your Shopify Admin, go to **Online Store > Themes**.
2. Click **Add theme > Upload zip file**.
3. Choose `autoads-shopify-theme.zip` from your Desktop.
4. Click **Upload file**.
